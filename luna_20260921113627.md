## Current status and evidence

README/manifest identify an Obsidian plugin that renames Markdown notes and generates YAML frontmatter through OpenRouter, with optional backups and one-time Constance credits. `manifest.json`, `main.ts`, `main.js`, assets, user guide, privacy references, and billing support are present.

## Issues and missing work

- Both source and built output are checked in, but no root package/build manifest was found in the sampled file list; release reproducibility and source-to-bundle parity need a documented build command.
- AI processing of note content is a privacy-critical behavior. The settings, fallback key path, prompts, logs, and backup behavior need a final data-flow review and clear default consent/disclosure.
- Billing and remote account integration add failure, refund, token-storage, and offline entitlement cases that need release tests.
- Public listing should avoid claims that exceed the current plugin behavior and should specify supported Obsidian versions.

## Store/community release gate

Obsidian Community Plugins are not mobile/desktop app stores. Confirm manifest metadata, license, support/privacy URLs, screenshots/GIF/video, release tag and bundled `main.js` parity, secret scans, and reviewer-ready data-handling notes. Monetization must remain optional and transparent, with no hidden note-content transmission.
